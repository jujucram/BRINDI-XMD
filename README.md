# BRINDI-XMD
BRINDI-XMD est un bot WhatsApp multi-fonctions développé avec Baileys. Il propose des commandes avancées pour la gestion de groupes, l’automatisation, l’intelligence artificielle, le téléchargement de médias et le divertissement. Rapide, puissant et personnalisable, il est conçu pour offrir une expérience WhatsApp complète et moderne.
