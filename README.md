## ⚡ FEATURES

- 👮 Admin commands (kick, ban, promote, demote)
- 🛡️ Protection system (antilink, antibot, antidelete)
- 🤖 AI integration (GPT, Gemini, Claude, DeepSeek)
- 🎮 Games (tictactoe, trivia, hangman)
- ⬇️ Downloader (YouTube, TikTok, Instagram, Spotify)
- 🎨 Media tools (sticker, removebg, meme, blur)
- 🔥 Fun commands (roast, couple, confession)
- 👑 Owner system (broadcast, sudo, settings)

## 📦 INSTALLATION

### 📌 Clone repository
- `git clone https://github.com/USERNAME/BRINDI-XMD.git`

- cd BRINDI-XMD

## 📌 Install dependencies
`Bash:
npm install`

## 📌 Start bot
`Bash:
npm start`
